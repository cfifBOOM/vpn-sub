# Telegram-бот

Бот раздаёт ключи из подписки этого репозитория: по 5 ключей для обычного интернета, для белых списков, по странам, ссылку-подписку с QR-кодом и инструкцию. Работает на Cloudflare Workers: бесплатно и без своего сервера. Свежие ключи сам подтягивает из ветки `sub`, обновлять его не нужно.

## Запуск

1. **Токен бота.** В Telegram открой @BotFather → `/newbot` → придумай имя и username (должен оканчиваться на `bot`) → скопируй токен вида `123456789:AA...`.
2. **Воркер.** Зарегистрируйся на dash.cloudflare.com (бесплатно) → Workers & Pages → Create → Hello World → Deploy → Edit code. Удали всё в редакторе, вставь содержимое `worker.js` → Deploy.
3. **Переменные.** В настройках воркера: Settings → Variables and Secrets → Add:
   - `BOT_TOKEN` — тип **Secret**, значение — токен из шага 1;
   - `REPO` — тип Text, значение — `логин/репозиторий` с подпиской;
   - `CHANNEL` — необязательно, `@канал`, тогда в меню появится кнопка «Канал».

   Нажми Deploy.
4. **Подключение к Telegram.** Открой в браузере `https://<имя-воркера>.<твой-поддомен>.workers.dev/setup`. Должны появиться строки «✅ Вебхук установлен» и «✅ Подписка найдена». После этого напиши боту `/start`.

Если адрес `*.workers.dev` не открывается, включи VPN: этот домен в России часто блокируют. Самому боту это не мешает, Telegram обращается к нему напрямую.

## Команды

`/start` — меню, `/keys` — ключи для обычного интернета, `/wl` — для белых списков, `/sub` — ссылка-подписка, `/countries` — по странам, `/help` — как подключить. Команды и описание бот прописывает себе сам при открытии `/setup`.
