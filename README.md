# Бесплатная VPN-подписка для России

Собирается автоматически каждые 3 часа из ~35 открытых репозиториев с бесплатными конфигами под РФ: дубли удаляются, у каждого сервера флаг страны и метка режима.

## Ссылки для VPN-клиента

Happ, v2RayTun, Hiddify, v2rayNG, Streisand, Karing и другие: «+» → «Добавить подписку по ссылке».

**Основная** (~1500 серверов, начинать с неё):
```
https://raw.githubusercontent.com/cfifBOOM/vpn-sub/sub/ru-vpn.txt
```

Запасная ссылка на неё же, если raw.githubusercontent.com не открывается (может отставать на несколько часов):
```
https://cdn.jsdelivr.net/gh/cfifBOOM/vpn-sub@sub/ru-vpn.txt
```

**Максимальное доверие** (~300): только VLESS Reality напрямую к серверу, проверены из РФ или подтверждены 4+ источниками, без серверов в РФ, Беларуси, Китае, Иране и Казахстане:
```
https://raw.githubusercontent.com/cfifBOOM/vpn-sub/sub/ru-vpn-trusted.txt
```

**Минимальный риск** (~1000, для личного пользования): только шифрованные протоколы с проверкой сертификата (Reality/TLS), без серверов в России:
```
https://raw.githubusercontent.com/cfifBOOM/vpn-sub/sub/ru-vpn-safe.txt
```

**Полная** — всё подряд, ~25 000 серверов, тяжело для телефона:
```
https://raw.githubusercontent.com/cfifBOOM/vpn-sub/sub/ru-vpn-full.txt
```

Для старых клиентов, которым нужен base64: `https://raw.githubusercontent.com/cfifBOOM/vpn-sub/sub/ru-vpn-base64.txt`

## Метки в названиях

- **ЧС** — обычный режим блокировок: домашний интернет и мобильный без ограничений.
- **БС** — может работать, когда на мобильном включены «белые списки»: сервер стоит в разрешённых диапазонах IP или маскируется под разрешённый сайт.

После обновления подписки запустите в клиенте проверку задержки и подключайтесь к самым быстрым.

## Как отбираются серверы

- Все конфиги [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia) — их проверяют прямо из России.
- Плюс серверы, которые независимо друг от друга есть у нескольких источников: ЧС — минимум у двух, БС — минимум у трёх.
- Не больше трёх вариантов одного и того же сервера.

Полный список источников — в [`build/sources.py`](build/sources.py). Чтобы добавить или убрать источник, отредактируйте этот файл, сборка запустится сама.

## Скрипт для телефона и роутера

[`termux/vpnsub.py`](termux/vpnsub.py) собирает те же подписки сам и проверяет серверы с твоего устройства — в Termux на Android или на роутере с OpenWrt, где он может каждые 3 часа класть лучшие ключи в Podkop. Подсказка по командам: `python3 vpnsub.py -h`.

## Telegram-бот

В папке [`bot`](bot) — бот, который раздаёт ключи из этой подписки. Как запустить — в [`bot/README.md`](bot/README.md).

## Важно

Это публичные бесплатные серверы неизвестных владельцев: сервера живут от часов до дней, а владелец может видеть ваш трафик. Не открывайте через них банк и важные аккаунты.
